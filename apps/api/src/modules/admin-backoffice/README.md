# admin-backoffice

Modulo dono de dashboards, filtros e operacoes administrativas transversais.

Estrutura prevista:
- `application/`: consultas e fluxos administrativos.
- `contracts/`: DTOs e schemas HTTP.
- `domain/`: policies e regras de backoffice.
- `infrastructure/`: composicao de repositorios e servicos admin.
- `routes/`: plugins Fastify e handlers HTTP.
