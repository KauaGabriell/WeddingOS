# photo-wall

Modulo dono de posts do mural, upload e moderacao.

Estrutura prevista:
- `application/`: criacao de post, listagem e moderacao.
- `contracts/`: DTOs e schemas HTTP.
- `domain/`: regras de post, moderacao e validacoes.
- `infrastructure/`: repositorios e adapters de storage.
- `routes/`: plugins Fastify e handlers HTTP.
