# gift-registry

Modulo dono de catalogo de presentes e reservas.

Estrutura prevista:
- `application/`: listagem, reserva e operacoes administrativas.
- `contracts/`: DTOs e schemas HTTP.
- `domain/`: regras de disponibilidade e reserva.
- `infrastructure/`: repositorios e persistencia transacional.
- `routes/`: plugins Fastify e handlers HTTP.
