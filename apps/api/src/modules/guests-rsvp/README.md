# guests-rsvp

Modulo dono de convidados, grupos e confirmacao de presenca.

Estrutura prevista:
- `application/`: casos de uso de home do convidado e RSVP.
- `contracts/`: DTOs e schemas HTTP.
- `domain/`: entidades e regras de elegibilidade e acompanhantes.
- `infrastructure/`: repositorios e mapeamentos de persistencia.
- `routes/`: plugins Fastify e handlers HTTP.
